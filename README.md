# Дмитрий — портфолио

Сайт-портфолио в виде рабочего стола в стиле начала 2000-х: загрузочный экран,
окна, которые можно таскать, папка «Работы», блокнот «Обо мне», мастер заявки.
Чистые HTML/CSS/JS — без сборки и зависимостей, работает на GitHub Pages.

```
index.html          — разметка, значки (SVG-спрайт), первый экран и текстовая версия
css/style.css       — оформление
js/config.js        — ВСЁ, что вы меняете: контакты, работы, услуги, этапы, отзывы, «Обо мне»
js/main.js          — окна, меню «Пуск», форма заявки, заставка
tools/build.js      — обновляет текстовую версию для поисковиков, sitemap.xml и версию файлов
assets/works/       — скриншоты работ: *.jpg (компьютер), *-thumb.jpg (миниатюра), *-m.jpg (телефон)
assets/wallpaper.svg, assets/favicon.svg, assets/og.jpg
404.html, robots.txt, sitemap.xml
```

## После любой правки

Запустите `node tools/build.js`: текст для поисковиков совпадёт с окнами, а телефоны посетителей
сразу получат новую версию, а не старую из кэша.

## Как добавить отзыв

Только настоящие. В `js/config.js` в список `reviews` добавьте блок:
`{ author: 'Имя', project: 'Какой сайт', text: 'Текст отзыва' }`, затем запустите сборку.
Пока список пуст, папка показывает «Отзывов пока нет».

## Как добавить цену к услуге

В `js/config.js` у нужной услуги заполните `price`, например `price: 'от 50 000 ₸'`.

## Как добавить работу

1. Сделайте скриншоты сайта: для компьютера (1200×750), миниатюру (480×300) и для телефона (390×844).
   Положите в `assets/works/` в формате JPG, например `shop.jpg`, `shop-thumb.jpg`, `shop-m.jpg`.
2. В `js/config.js` в список `works` добавьте блок по образцу. Если проект учебный или демо, так и напишите в `status`.
3. Запустите `node tools/build.js`.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com. Чтобы адрес был коротким — назовите его
   `<ваш-логин>.github.io`, тогда сайт откроется прямо по `https://<ваш-логин>.github.io/`.
2. Загрузите в него все файлы этой папки (**Add file → Upload files**).
3. **Settings → Pages**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт заработает.

> Страница 404 рассчитана на сайт в корне домена (`<логин>.github.io` или свой домен).

## Свой домен (например, `dmitrii.studio`)

1. Купите домен у регистратора.
2. В репозитории: **Settings → Pages → Custom domain** — впишите домен, Save.
   GitHub сам создаст файл `CNAME`.
3. У регистратора в DNS добавьте:
   - для `dmitrii.studio` — четыре A-записи: `185.199.108.153`, `185.199.109.153`,
     `185.199.110.153`, `185.199.111.153`;
   - для `www` — CNAME-запись на `<ваш-логин>.github.io`.
4. Когда домен заработает, включите **Enforce HTTPS**.
5. В `js/config.js` поменяйте `url` на новый домен, в `robots.txt` — адрес sitemap, и запустите `node tools/build.js`.

## Про стиль

Это оммаж эпохе, а не копия: логотип, обои и все иконки нарисованы с нуля,
фирменных логотипов, обоев и звуков Microsoft на сайте нет. Если захотите
поменять «бренд» на загрузочном экране — он в `index.html`, блок `.boot`.
