# Дмитрий Уваров — портфолио

Сайт-портфолио в виде рабочего стола в стиле начала 2000-х: загрузочный экран,
окна, которые можно таскать, папка «Работы», блокнот «Обо мне», мастер заявки.
Чистые HTML/CSS/JS — без сборки и зависимостей, работает на GitHub Pages.

```
index.html          — разметка и все иконки (SVG-спрайт)
css/style.css       — оформление
js/config.js        — ВСЁ, что вы меняете: контакты, работы, текст «Обо мне», фото
js/main.js          — окна, меню «Пуск», мастер заявки, загрузка
assets/works/       — скриншоты работ (компьютер + телефон)
assets/wallpaper.svg, assets/favicon.svg, assets/og.png
404.html            — страница «Файл не найден»
```

## Перед публикацией — обязательно

Откройте `js/config.js` и замените:

- `telegram: 'YOUR_TELEGRAM'` — ваш ник в Telegram без `@`;
- `email: 'hello@example.com'` — ваша почта;
- `whatsapp` и `github` — по желанию (пустая строка = пункт не показывается);
- `avatar` — путь к вашему фото для меню «Пуск» (по желанию).

## После любой правки

В `index.html` у файлов стили и скриптов стоит `?v=…` — поменяйте это число (например, на текущие дату и время)
в трёх местах. Иначе телефоны посетителей ещё какое-то время показывают старую версию из кэша.

## Как добавить работу

1. Сделайте два скриншота сайта: для компьютера (1440×900) и для телефона (390×844).
   Положите в `assets/works/`, например `shop.png` и `shop-m.png`.
2. В `js/config.js` в список `works` добавьте блок по образцу существующих.
3. Если сайт опубликован — впишите ссылку в `url`, появится кнопка «Открыть сайт».

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com. Чтобы адрес был коротким — назовите его
   `<ваш-логин>.github.io`, тогда сайт откроется прямо по `https://<ваш-логин>.github.io/`.
2. Загрузите в него все файлы этой папки (**Add file → Upload files**).
3. **Settings → Pages**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт заработает.

> Страница 404 рассчитана на сайт в корне домена (`<логин>.github.io` или свой домен).

## Свой домен (например, `uvarov.studio`)

1. Купите домен у регистратора.
2. В репозитории: **Settings → Pages → Custom domain** — впишите домен, Save.
   GitHub сам создаст файл `CNAME`.
3. У регистратора в DNS добавьте:
   - для `uvarov.studio` — четыре A-записи: `185.199.108.153`, `185.199.109.153`,
     `185.199.110.153`, `185.199.111.153`;
   - для `www` — CNAME-запись на `<ваш-логин>.github.io`.
4. Когда домен заработает, включите **Enforce HTTPS**.
5. В `index.html` поменяйте `og:image` на полный адрес: `https://uvarov.studio/assets/og.png` —
   так превью ссылки будет корректно показываться в Telegram и WhatsApp.

## Про стиль

Это оммаж эпохе, а не копия: логотип, обои и все иконки нарисованы с нуля,
фирменных логотипов, обоев и звуков Microsoft на сайте нет. Если захотите
поменять «бренд» на загрузочном экране — он в `index.html`, блок `.boot`.
